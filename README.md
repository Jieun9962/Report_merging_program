# portfolio🐇
I planned, designed, and built this portfolio myself, from the initial structure down to the code. Every visual element was made from scratch, with accessibility and usability in mind from the beginning rather than added later.
The goal is to demonstrate not only my professional experience in web accessibility, but also how accessibility can enhance usability and create a better experience for everyone.

## Live Demo
🌐 https://Jieun9962.github.io/

## Project Goals
- Build an accessible portfolio following WCAG guidelines
- Demonstrate accessibility-first design principles
- Provide responsive layouts across devices
- Improve keyboard navigation and screen reader compatibility
- Create an inclusive experience for all users

## Design & Development
Unlike many portfolio websites built from templates, this portfolio was designed and developed entirely by me.
This includes:
- Information Architecture
- UX Planning
- UI Design
- Custom Illustrations & Graphics
- Responsive Web Design
- Front-end Development
- Accessibility Testing
- Accessibility Optimization

 ## Accessibility Features
This project was developed with accessibility in mind.
Implemented features include:
- Semantic HTML structure
- Keyboard-only navigation
- Visible focus indicators
- Appropriate heading hierarchy
- Alternative text for images
- Color contrast following WCAG recommendations
- Responsive design
- Screen reader compatibility
- ARIA attributes where appropriate

## Behind this portfolio
Everything here, the information architecture, UI design, responsive layouts, illustrations, and front-end code, is my own work. Accessibility wasn't something I checked off at the end. It shaped decisions throughout the process, from how I organized content to how I wrote the markup.
